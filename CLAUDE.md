# CLAUDE.md

Context for Claude Code sessions in this repository.

## Project

Replication of the Reinhart & Rogoff (2010) debt–growth table, following the corrected replication by
Herndon, Ash & Pollin (2014), then extended with a split by monetary regime (own floating currency vs
peg / monetary union). Empirical groundwork for chapter 3.2 of the author's bachelor's thesis. Thesis
context lives in a separate private repository (`../licencjat-mmt`, if present on this machine).

## How we work: learning mode

- The author is a Python beginner (learning since August 2026). **The author writes the code; Claude
  guides one step at a time**, explains, gives hints and checks results. Claude does not write whole
  notebooks or functions. A full solution only on explicit request, explained line by line.
- Every exercise uses the same format: task / new knowledge needed / anatomy on a *different* example
  / acceptance tests (at least two cases).
- Talk to the author in **Polish**. Code, comments, commit messages and README stay in **English**.
- The author makes the commits and must be able to explain what each one changes.
- Python computes, a language model explains: no number in this project comes from an LLM.

## Environment

- Managed with [uv](https://docs.astral.sh/uv/): `uv sync`, Python 3.12, interpreter in `.venv`.
- Notebooks: VS Code with the `.venv` kernel, or `uv run jupyter lab`.
- Two machines (Windows and Mac): `git pull` at the start, commit and push at the end.

## Data rules

- `data/raw/` is read-only: never edit or overwrite. Derived data goes to `data/processed/`
  (git-ignored, regenerated by code).
- Starting file: `data/raw/hap-2013-05-17/RR-keycolumns.xlsx` with columns Country, Year, debtgdp,
  dgcat, dRGDP; 20 countries, 1946–2009, 1275 rows, 1175 with both debt and growth.
- HAP's own code and output (`RR.R`, `RR.Rout`) are the reference for every number.

## Replication targets

Mean real GDP growth (%) by public debt/GDP category, 1946–2009 (from `RR.Rout`):

| Version | 0–30% | 30–60% | 60–90% | >90% |
|---|---|---|---|---|
| HAP corrected (all country-years, equal weight per year) | 4.174 | 3.092 | 3.187 | 2.168 |
| RR published (country weights, excluded years, spreadsheet error, NZ transcription) | 4.089 | 2.854 | 3.399 | −0.062 |
